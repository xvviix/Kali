🐉 راهنمای Kali

بخش ۱ — مبانی و راه‌اندازی Kali

نصب، مدیریت پکیج، کاربران و سیستم — پایه‌ای که هر تست امنیتی روی آن بنا می‌شود.

kali-setupراه‌اندازی اولیه و توزیع ابزارها

Kali مدرن با منوی kali-setup (نسخه‌های قدیمی‌تر: kali-tweaks) اجازه می‌دهد سیستم‌فایل را «همه‌جا نوشت‌نی» (persistence) انتخاب کنید و مجموعه‌ابزارها (metapackages) را هنگام نصب تعیین کنید.

# دسترسی به منوی تنظیمات
sudo kali-tweaks          # منوی قدیمی (نسخه‌های پیشین)
kali-setup                # منوی جدید نصب/پیکربندی

برای Live USB با ذخیره‌سازی دائمی، هنگام ساخت USB با Rufus یا balenaEtcher، پارتیشن persistence بسازید و با cryptsetup رمزنگاری کنید.

aptمدیریت پکیج — قلب نگهداری Kali

Kali بر پایه Debian است؛ پس apt همان شناخته‌شده است، با ریپازیتوری Kali (kali-rolling).

sudo apt update && sudo apt full-upgrade -y   # بروزرسانی کامل
sudo apt install burpsuite nmap             # نصب ابزار
sudo apt remove --purge tool && sudo apt autoremove   # حذف
apt search metasploit                       # جست‌وجوی پکیج
apt policy metasploit-framework            # نسخه موجود/نصب‌شده
💡 ریپازیتوری kali-rolling را تغییر ندهید؛ همه ابزارها از آن می‌آیند. اگر apt update خطای کلید داد: sudo wget -q -O - https://archive.kali.org/archive-key.asc | sudo apt-key add -

metapackagesمجموعه‌ابزارهای آماده

به‌جای نصب تک‌تک ابزارها، متاپکیج‌ها کل خانواده یک حوزه را نصب می‌کنند.

sudo apt install kali-tools-information-gathering
sudo apt install kali-tools-vulnerability
sudo apt install kali-tools-web
sudo apt install kali-tools-passwords
sudo apt install kali-tools-wireless
sudo apt install kali-tools-forensics
sudo apt install kali-tools-exploitation
sudo apt install kali-tools-hardware
sudo apt install kali-tools-database
sudo apt install kali-tools-reverse-engineering
sudo apt install kali-desktop-gnome          # دسکتاپ جایگزین
sudo apt install kali-linux-everything      # همه‌چیز (سنگین!)

لیست کامل: apt search kali- | less

user / sudoکاربر root در مقابل kali

از نسخه 2020.1، Kali دیگر به‌صورت پیش‌فرض root نیست؛ کاربر kali با دسترسی sudo.

# فعال‌کردن پسورد root (اگر لازم دارید)
sudo passwd root
# افزودن کاربر جدید با دسترسی sudo
sudo adduser matin
sudo usermod -aG sudo matin
# بازگشت به حالت استاندارد
sudo passwd -l root   # قفل‌کردن root
⚠️ با ابزارهای گرافیکی مثل Burp، Wireshark و به‌خصوص msfconsole با کاربر عادی + sudo کار کنید؛ اجرای کل دسکتاپ به‌صورت root باعث مشکلات پایداری و امنیتی می‌شود.

servicesسرویس‌های داخلی Kali

در Kali سرویس‌ها به‌صورت پیش‌فرض خاموش‌اند — امن‌تر — و فقط هنگام نیاز روشن کنید.

sudo systemctl start postgresql       # لازم برای msfdb (Metasploit)
sudo systemctl start apache2          # سرویس وب برای serving فایل‌ها
sudo systemctl enable --now ssh       # ssh سرور
sudo systemctl mask apache2           # غیرفعال‌کردن دائمی تا نیاز بعدی

hygieneبهداشت سیستم و بکاپ

ابزارها فقط وقتی معتبرند که به‌روز باشند و مخزن دستورات شما مرتب باشد.

# هفته‌ای یک‌بار، قبل از هر engagement
sudo apt update && sudo apt full-upgrade -y
# اسنپ‌شات VM قبل از هر پروژه (VirtualBox/VMware)
# ذخیره خروجی‌ها با تاریخ
mkdir -p ~/eng/$(date +%F)-target && cd $_
history -w ~/.bash_history         # ذخیره تاریخچه
export HISTTIMEFORMAT="%F %T  "      # مهرزمان در history

WSL و کانتینر

wsl --installKali در ویندوز

# در PowerShell (مدیر)
wsl --install -d kali-linux
wsl -d kali-linux                    # ورود
# داخل Kali WSL:
sudo apt update && sudo apt full-upgrade -y
sudo apt install kali-win-kex        # حالت گرافیکی (Win-KeX)
kex --win -s                         # دسکتاپ کامل در ویندوز

dockerKali به‌صورت کانتینر

docker run --rm -it kalilinux/kali-rolling
docker run --rm -it kalilinux/kali-rolling apt update
# پایدار با هوم مپ‌شده:
docker run --rm -it -v $PWD:/data kalilinux/kali-rolling bash
