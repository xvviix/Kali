بخش ۴ — وایرلس، فارنزیک و گزارش

گوشه‌های تخصصی Kali: شبکه‌های بی‌سیم، تحلیل شواهد دیجیتال، و مهارتی که همه‌چیز را کامل می‌کند: گزارش‌نویسی.

airmon-ng suiteاسکن و حمله به شبکه‌های Wi-Fi

sudo airmon-ng check kill        # قطع تداخل سرویس‌ها
sudo airmon-ng start wlan0       # ساخت wlan0mon
sudo airodump-ng wlan0mon        # دیدن همه APها و کلاینت‌ها
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w cap wlan0mon
# در ترمینال دیگر — گرفتن هندشیک (فقط روی شبکه خودتان!)
sudo aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF -c CLIENT_MAC wlan0mon
# کرک هندشیک:
aircrack-ng -w /usr/share/wordlists/rockyou.txt cap-01.cap
# پایان کار:
sudo airmon-ng stop wlan0mon
⚠️ حمله به شبکه‌های وایرلسی که مال شما نیستند غیرقانونی است — این دستورات فقط برای lab شخصی و CTF. سادگی: wifite همه این مراحل را خودکار می‌کند: sudo wifite

tsharkخط فرمان Wireshark

sudo tshark -i eth0 -w capture.pcap
sudo tshark -i eth0 -Y "http" -T fields -e ip.src -e http.request.full_uri
sudo tshark -r capture.pcap -Y "tcp.port==443" | head
tshark --version | head -1

volatilityتحلیل حافظه RAM (فارنزیک)

# نسخه ۲:
python2 vol.py -f memory.dmp imageinfo

# نسخه ۳ (kali-rolling):

binwalkکاوش فایل‌های ترکیبی و فریم‌ورها

binwalk firmware.bin                 # شناسایی امضاهای داخلی
binwalk -e firmware.bin              # استخراج خودکار
binwalk --dd=".*" firmware.bin      # استخراج همه‌چیز

exiftoolمتادیتا — گاهی همه‌چیز در توضیحات تصویر است

exiftool photo.jpg
exiftool -a -u -g1 photo.jpg         # همه تگ‌ها شامل مخفی
cp photo.jpg photo_clean.jpg
exiftool -all= -overwrite_original photo_clean.jpg   # حذف متادیتا از نسخه کپی

sha256sumتمامیت و زنجیره نگهداری شواهد

روی اصل شواهد کار نکنید. یک نسخه فقط‌خواندنی نگه دارید، هش را قبل و بعد ثبت کنید و زمان/مالک هر انتقال را بنویسید.

sha256sum evidence.img | tee evidence.img.sha256
sha256sum -c evidence.img.sha256
stat --format='%n | %s bytes | %y' evidence.img
# مونت فقط‌خواندنی نمونه:
sudo mount -o ro,loop,noexec evidence.img /mnt/evidence

file / strings / yaraتریاژ اولیه فایل

file suspicious.bin
sha256sum suspicious.bin
strings -a -n 8 suspicious.bin | less
xxd -l 128 suspicious.bin
yara -r rules/ sample-directory/
⚠️ فایل ناشناس را روی میزبان اصلی اجرا نکنید. تحلیل پویا باید در VM ایزوله، بدون پوشه مشترک و با شبکه کنترل‌شده انجام شود.

reportingگزارش‌دهی — مهارت واقعی حرفه‌ای

هکر خوب گزارش خوب می‌نویسد. مشتری خروجی شما را از گزارش می‌فهمد، نه از ترمینال.

  • خلاصه اجرایی برای مدیران: ریسک، بدون اصطلاح فنی.
  • یافته‌ها: هر مورد با شدت (Critical/High/Medium/Low)، مراحل بازتولید، تصویر، و راه‌حل.
  • مستندات: زمان‌بندی، ابزارها، دستورات دقیق.
# ساختار پیشنهادی پروژه
mkdir -p ~/eng/{recon,exploit,loot,report,screens}
# ثبت همه اسکن‌ها از همان اول:
nmap -sV -oA recon/initial 10.10.10.5
# در پایان، خروجی‌ها را به گزارش پیوست کنید.

⭐ برگه تقلب نهایی

# ── بروزرسانی ──
sudo apt update && sudo apt full-upgrade -y
# ── شناخت ──
sudo nmap -sV -sC -oA recon/initial TARGET
gobuster dir -u http://TARGET -w /usr/share/wordlists/dirb/common.txt
# ── نفوذ ──
searchsploit SERVICE VERSION
msfconsole -q -x "search TYPE:version"
# ── پسورد ──
hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://TARGET
hashcat -m 1800 hashes.txt rockyou.txt
# ── اضطراری: هیچی کار نکرد؟ ──
sudo tcpdump -i tun0 -A | head          # ترافیک خودت را ببین
ls -la /var/www/html/ ; cat /etc/crontab # مکان‌های کلاسیک
🌱 یادگیری در Kali با «مجوز» شروع می‌شود، نه با دستور. هک‌باکس، TryHackMe، Proving Grounds و VMهای خودتان — بعد از آن، دنیای واقعی.
