بخش ۲ — شناخت و اسکن

قبل از هر حمله، باید بدانید چه چیزی در مقابل شماست. این بخش از عمومی به جزئی می‌رود: هاست، پورت، سرویس، دامنه.

nmapپادشاه اسکنرها

# اسکن سریع ۱۰۰ پورت پرتکرار
sudo nmap -T4 -F 10.10.10.5
# اسکن کامل پورت‌ها (TCP) با تشخیص سرویس/نسخه
sudo nmap -p- --min-rate 5000 -T4 10.10.10.5
sudo nmap -sV -sC -p 22,80,443 10.10.10.5
# اسکن UDP (کند است؛ پورت‌های کلیدی)
sudo nmap -sU --top-ports 50 10.10.10.5
# اسکریپت‌های NSE — مثال‌های پرکاربرد
sudo nmap --script vuln -p 80,443 10.10.10.5
sudo nmap --script smb-vuln* -p 139,445 10.10.10.5
# خروجی ساختاریافته
sudo nmap -sV -oA scan_target 10.10.10.5   # متن + xml + grep
💡 -sV نسخه سرویس را می‌خواند؛ -sC اسکریپت‌های پیش‌فرض را اجرا می‌کند. -oA برای گزارش‌گیری همیشه بزنید.

masscanاسکن کل اینترنت در دقیقه‌ها

برای رنج‌های بزرگ IP — سرعت nmap را ندارد در دقت، اما در سرعت بی‌رقیب است.

sudo masscan 10.10.10.0/24 -p 80,443 --rate 1000
sudo masscan 10.10.10.0/24 -p 1-65535 --rate 10000 > mass.txt
# سپس پورت‌های یافته‌شده را با nmap دقیق بروید:
nmap -sV -p $(grep -oP "\d+(?=/tcp)" mass.txt | tr "\n" "," | sed "s/,$//") 10.10.10.5

netdiscover / arp-scanکشف هاست‌های محلی

sudo netdiscover -r 10.10.10.0/24
sudo arp-scan --localnet
sudo arp-scan 10.10.10.0/24 --interface eth0

enum4linux / smbclientشمارش SMB

enum4linux -a 10.10.10.5 | tee enum.txt
smbclient -L //10.10.10.5 -N            # لیست شیرهای ناشناس
smbclient //10.10.10.5/share -N         # اتصال به شیر
smbclient //10.10.10.5/share -U "user%pass"
# داخل شیر: ls, get file, put file
nbtscan 10.10.10.5                     # NetBIOS

whatwebانگشت‌نگاری وب‌سایت

whatweb http://10.10.10.5
whatweb -a 3 http://site.com            # سطح تجزیه‌ی تهاجمی‌تر

theHarvesterجمع‌آوری ایمیل/ساب‌دامنه از منابع عمومی

theHarvester -d company.com -l 200 -b google,bing,crtsh
theHarvester -d company.com -b linkedin   # نام کارکنان

amassنقشه‌برداری حرفه‌ای زیرساخت دامنه

amass enum -d company.com -o amass.txt
amass enum -passive -d company.com        # فقط منابع عمومی
amass viz -d3 company.com                 # نمودار گرافی

dnsrecon / digبررسی DNS و transfer

dnsrecon -d company.com -t std
dnsrecon -d company.com -t axfr         # تلاش zone transfer
dig axfr company.com @ns1.company.com
dig +short mail.company.com; host -t MX company.com
📚 روش درست recon: عمومی (whois/Google) → دامنه (amass) → هاست (nmap -sn) → پورت (-p-) → سرویس (-sV) → شمارش (enum4linux/whatweb) → سپس فاز اکسپلویت بخش ۳.
